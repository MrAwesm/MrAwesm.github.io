## 写在前面：三者其实共享同一条主轴

读这篇之前，先记住一句话：

> **这三类模型，本质都在做同一件事——把世界变成一串符号，然后预测下一个符号。**

区别只在于这串符号里装的是什么：

- **LLM**：装的是文字 token。
- **VLA**：装的是图像 + 文字 + 动作 token。
- **世界模型**：装的是抽象的"状态" + 动作，目标是预测未来状态。

掌握了这条主轴，下面所有细节都是它的展开。

## 一、LLM：从"猜词游戏"里长出的智慧

### 1.1 核心直觉：把人类知识压进一个"接话茬"机器

想象一个总爱接你话茬的朋友。你说"今天天气真——"，他接"热，得开空调"。如果这位朋友读过几乎所有书、网页和代码，他的接话就可能延伸到写诗、解题、写程序。

**大语言模型的核心，就是一个被训练来"接话茬"的神经网络。** 它的第一性原理简单得几乎可疑：

> 根据前面所有的文本，计算下一个词的概率，挑一个输出，把它拼回去，再预测下一个。如此循环。

这个循环叫**自回归生成**（autoregressive generation）。

你可能会困惑：这么朴素的"猜词"，怎么会产生逻辑、知识和创造力？关键在于：**为了猜得准，模型被迫在内部消化整个世界的规律。** 比如要在"水的化学式是__"后面正确接上"H₂O"，它必须真的"学到"化学知识——没人主动告诉它，但不学就猜不对，损失函数就会惩罚它。

所以，**LLM 的本质是一个巨大的"世界知识压缩包"，压缩的载体就是序列生成的能力。**

### 1.2 细粒度拆解：从文字到概率，中间发生了什么

我们把镜头推近，看一个现代大模型（GPT 系列）肚子里有什么。

**(1) 分词——把语言切成"乐高积木"**

计算机不认识字，只认识数字。第一步是把文本切成小块，每块叫一个 **token**。token 不是严格的单词：英文的 "learning" 可能被切成 "learn" + "ing"；常用中文可能一个字就是一个 token。每个 token 在词表里有个编号，"我爱你"可能就变成 `[15, 38, 22]`。

为什么要切？因为世界上不可能为每个句子建一张表，必须用**有限积木拼无限意义**——52 张扑克牌能组合出无穷牌面，逻辑相同。

**(2) 嵌入——给每个积木附上"语义指纹"**

光有编号不够，编号 15 和 38 之间没有天然关系。**嵌入层**（embedding）把每个 token 映射到一个几百到几千维空间中的一个点，这个点的坐标向量就是该 token 的"语义指纹"。经过训练，意思相近的词，向量会靠得很近；还会出现"国王 − 男人 + 女人 ≈ 王后"这样的向量运算。

> ⚠️ 一个容易混淆的点：这种"向量运算"最初是在 Word2Vec 那一代**静态词向量**上被发现的。在现代 LLM 里，同一个词在不同上下文中得到的向量是**动态变化**的——"猫"在"猫很可爱"和"猫（modem）拨号上网"里，向量完全不同。这个动态特性正是下一步"注意力"带来的。

**(3) Transformer 的心脏：用"注意力"看清全句关系**

这是 LLM 最核心的引擎。想象你站在一个嘈杂的鸡尾酒会里，想听清某个人说话——你的大脑会自动聚焦他的声音、压低背景噪音。**注意力机制**（attention）干的就是这件事。

在模型里，每个 token（比如"猫"）都会对其他所有 token 发出三个询问，对应三组向量：

- **查询（Query）**："我"需要从别人那里得到什么？
- **键（Key）**："我"能提供什么？
- **值（Value）**："我"实际携带的内容是什么？

"猫"拿自己的查询去和所有词的键算匹配分数，分数越高越相关，再用这些分数当权重，把所有词的值向量加权求和——得到的，就是"猫"结合了上下文之后的**新表示**。

这意味着同一个"猫"，在"猫很可爱"里和"我家的猫（调制解调器）连不上网"里，最终表示完全不同：前者被"可爱"拉过去，后者被"拨号/网络"拉过去。**注意力让每个词动态地"看见"整句话。**

需要强调：Q/K/V 不是数据库里那种人工定义的字段，它们都是**模型自己学出来的数字矩阵**，目的就是让每个词根据上下文调整自己。

**多头注意力**（multi-head attention）就是同时开好几组这样的"小会议"，每组关注不同维度的关系（语法、语义、指代、位置……），最后把结果拼起来，从而捕捉到丰富的语言结构。

**(4) 前馈网络与残差连接——深化理解，且不忘本**

注意力之后，每个 token 还会经过一个全连接层（前馈网络），相当于给每个词独立做一轮"深度思考"，对刚收集到的上下文做一次非线性变换，提取更高阶的特征。

这里有个关键设计叫**残差连接**（residual connection）：每一层的输入会原封不动地加到该层输出上。你可以把它想成递纸条——可以补充新信息，但旧信息不会丢。这样即便网络堆到上百层，信息也不会在传递中消失，训练才稳定。

**(5) 从概率到下一个词**

经过几十层"注意力 + 前馈 + 残差"模块后，最后一个 token 的最终表示会经过一个线性层和 **softmax**（一个把任意实数变成概率分布的函数），输出词表里每个词接在后面的可能性。比如"天空是"后面，"蓝色"概率 0.7，"黑色" 0.1，"极限" 0.05。

生成时，模型**不是每次都选概率最高的词**——那样会陷入枯燥循环。它会引入"温度"（temperature）控制随机性：低温更确定、保守，高温更有创造力、更敢冒险。

### 1.3 从"接话茬"到"听话的助手"

原始 LLM 只会接话茬。你问"怎么做红烧肉"，它可能接"第一步准备五花肉……"因为它见过无数菜谱；你问"解释量子纠缠"，它可能接"是一个复杂的概念，下面我们来详细讲解"——因为它见过教科书式的开头。但这种行为不稳定，也不可控。

为了让 LLM 变成真正听话的助手，人类做了**对齐训练**：先收集人类对回答好坏的排序，训练一个奖励模型，再用强化学习让 LLM 倾向于生成高分回答——这就是 **RLHF**（Reinforcement Learning from Human Feedback）的大致思路。

到这里，一个原始"接话茬机器"就变成了有指令跟随能力的 ChatGPT。但请注意：**它的本质仍是预测下一个 token，只是行为空间被人类偏好修剪过。**

## 二、VLA 模型：给语言模型装上眼睛和手

### 2.1 核心直觉：把动作也变成 token

VLA 全称 **Vision-Language-Action**（视觉-语言-动作）。它要解决的问题是：怎么让机器人听懂人话、看清环境，并直接输出动作序列。

回到第一性原理。LLM 之所以强大，是因为它把所有文本任务都统一成了"序列生成"。那么——**如果能把摄像头看到的图像、机器人关节的运动也表达成序列，是不是就能用同一个强大的序列模型来处理？**

VLA 的第一性原理由此浮现：

> 把视觉、语言、动作**全部转化为统一的 token 序列**，然后像 LLM 一样预测下一个 token——只不过这个 token 可能是文字，也可能是机械臂的关节角度。

这样机器人就直接继承了 LLM 里蕴含的世界常识和推理能力。比如它知道"把易拉罐扔进蓝色垃圾桶"里，易拉罐通常是铝制的、蓝色垃圾桶通常代表可回收——这些语义知识能帮它识别物体、理解目标。

### 2.2 细粒度拆解：动作是怎么"说"出来的

**(1) 让图片也变成 token**

文字好办，切成 token 就行；图片怎么办？通常用一个预训练视觉编码器（如 ViT，或 CLIP 的视觉塔），把图像切成很多小块（patch），每块当成一个"视觉词"，全部转成一串特征向量。再通过一个映射层，把这些向量变成和语言 token 形式相同的嵌入。

于是模型眼里不再有"图"和"文"的区别，全是**一维的向量序列**。

**(2) 让动作也变成 token——以及 2024 年的关键突破**

机器人的动作通常是连续数值，比如机械臂末端的 6 自由度位移和旋转。怎么让它像单词一样被处理？

**早期路线（RT-2 等为代表）：离散化。** 把每个自由度的取值范围均匀分箱，比如把 360° 旋转切成 256 个区间，每个区间对应一个动作 token。这样一个动作就被表示成一小串离散数字，"向左转 15°"可能就是 `[动作token 128, 动作token 57, ...]`。之所以要离散化，是因为 LLM 的核心操作是在离散 token 上算概率分布，连续值无法直接套交叉熵损失。

**2024 年的突破：连续动作输出。** Physical Intelligence 的 **π₀**（2024 年 10 月）指出：把精细动作硬塞进离散桶会损失精度，对灵巧操作（叠衣服、折纸盒）是致命的。他们的做法是保留 LLM 的语言理解主干，但在动作输出端接一个 **flow matching**（流匹配）模块，直接生成**连续**的动作轨迹。这成为新一代 VLA 的范式转折——VLA 不必再"假装动作是单词"。

**(3) 混合序列，一视同仁**

现在一条机器人交互数据可以被编织成这样一个序列：

```
[图像 token 序列] [指令："把苹果放到盘子里"的文本 token] [动作 token 序列]
```

训练时，模型看到前面的图像和指令，就要预测动作 token（或连续动作）——这和训练 LLM 时"看上文、预测下文"完全是同一回事，损失函数也长得一样。

因为模型主体经常直接复用一个在互联网图文上预训练好的 LLM，所以它天生就具备语言理解、视觉常识，甚至一些基础物理直觉（"苹果是圆的、会滚"）。这是 VLA 最迷人的效应：**语言模型里的世界知识，通过序列统一，变成了机器人操作的能力。**

### 2.3 涌现能力：没教过的，也能做

只要数据够多，端到端 VLA 会出现惊人的涌现行为。比如只教过它"拿起可乐罐"，没教过"拿起雪碧罐"，但它见到雪碧罐也能拿起——因为从语言和视觉特征上，它已经知道"雪碧"和"可乐"都是需要抓握的罐装物体。

更神奇的是语义迁移：你给它一张泰迪熊的图片，说"把这个递给小朋友"，它可能做出轻柔递出的动作，因为语言模型里"泰迪熊"与"柔软、拥抱"关联。这正是 VLA 超越传统机器人编程的地方——**它把语义理解带进了物理世界**。

### 2.4 这两年的关键进展（2024–2026）

VLA 是过去两年节奏最快的赛道，主线很清楚：

| 时间 | 模型 | 关键贡献 |
|------|------|---------|
| 2023 | **RT-2**（Google）| 首次证明"把动作离散成 token、塞进 VLM"可行，VLA 概念立住 |
| 2024.06 | **OpenVLA**（Stanford/Berkeley）| 7B 参数、970K 真机示教数据训练的**首个全开源可商用** VLA |
| 2024.10 | **π₀**（Physical Intelligence）| 用 flow matching 输出**连续动作**，灵巧操作能力大幅跃升 |
| 2025 | **Gemini Robotics**（DeepMind）| 强 zero-shot 泛化，跨形态、跨任务的通用性演示 |

一句话概括趋势：**从"动作伪装成语言"，进化到"为动作专门设计输出头"**；从单一任务，进化到通用策略。

## 三、世界模型：在脑内放映未来

### 3.1 核心直觉：你天生就有一个世界模型

闭眼想象一下：把桌上的一杯水推一下。你大概能"看到"杯子滑动、水洒出来、杯子在桌边停住。你并没真的去推，但你的大脑已经根据对物理规律的认知，快速**模拟**了未来。

这个在大脑内部运行、能根据当前状态和动作预测下一时刻状态的机制，就是**世界模型**。

在 AI 中，它的第一性原理是：

> 学习一个对环境的内部表征，并能根据这个表征和候选动作，预测下一状态和潜在奖励——从而可以在"想象"中规划，而不是在现实里盲目试错。

注意它和 LLM"预测下一个词"的根本区别：

- LLM 预测基于**语料里的统计关联**，它是被动的，不能主动改变环境。
- 世界模型必须回答：**"如果我这样做，世界会怎样？"** ——它要响应**干预**。

需要严谨地说：现有世界模型学到的，大多还是**关联和预测**，而不是哲学意义上的"真正因果"。但相对 LLM，它显式地把"动作"作为输入，已经向因果方向迈出了一步——这是它和纯生成模型的分水岭。

### 3.2 两条路线之争：预测像素，还是预测抽象？

世界模型当下最大的分歧，是**在什么空间里做预测**。

**路线 A：预测像素（生成式）**。代表是 OpenAI Sora、DeepMind **Genie 2**（2024 年 12 月）。它们直接生成未来视频帧，能从一张图生成可交互、可游玩的 3D 世界，画面惊艳、时空连续。它们的优点是直观、可演示；缺点是把算力大量消耗在"每一片树叶怎么晃"这种**与决策无关的细节**上。

**路线 B：预测抽象表征（JEPA 派）**。这是 Yann LeCun 一直倡导的方向，代表是 Meta 的 **V-JEPA 2 / 2.1**（2025）。它的核心信条是：

> **世界模型应该学会"忽略"。** 在抽象的潜空间里预测那些可预测、有意义的东西，对那些不可预测的像素级噪声直接放弃。

JEPA（Joint-Embedding Predictive Architecture，联合嵌入预测架构）不要求模型重构每一帧像素，只要求它在**潜表征空间**里让"预测的未来状态"和"真实的未来状态"在某个抽象层面上接近。LeCun 认为，这才是通向真正能理解物理世界、能规划的智能体的正路——V-JEPA 2.1 已经能在真实机械臂上做 zero-shot 抓取与放置，证明这条路走得通。

这两条路线的对立，本质是对"什么是有效信息"的回答不同。

### 3.3 细粒度拆解：一个完整世界模型长什么样

不论哪条路线，一个用于决策的世界模型通常包含三件套：

**(1) 编码器：把高维输入压成"潜状态"**

真实世界太复杂，没法逐个原子去模拟。世界模型会学习一个抽象、压缩的内部状态表示，称为**潜变量**。模拟一个钟摆，大脑不需要记录每根纤维的位置，只要知道角度和角速度——这就是潜空间。编码器把图像、传感器数据压缩成潜状态，必要时配一个解码器从潜状态还原观察，确保关键信息不丢。

为什么不直接用原始像素？因为像素级预测计算量巨大，又容易陷入噪声细节、学不到结构。**潜空间让模型脱离低层细节，去捕捉抽象的"因果状态"。**

**(2) 转移模型：脑内的物理引擎**

潜空间里还需要一个**动态模型**（也叫转移模型）。它接收当前潜状态和一个动作 *a*，输出下一时刻的潜状态预测。这是"模拟器"的核心，可以是循环网络，也可以是 Transformer。训练它只需要让预测的下一状态和真实发生的下一状态尽量接近。

**(3) 奖励与价值：想象里也要打分**

光预测未来还不够用于决策。世界模型通常还会学一个**奖励模型**（评估某个状态好不好）和一个**价值模型**（估计从当前状态出发、按某策略走能拿到多少长期累积奖励）。

有了这三件套，智能体就能在世界模型的"想象空间"里展开成千上万条虚拟轨迹，用规划算法挑奖励最高的，或者直接在想象中做强化学习。

**典型案例：Dreamer 系列。** Dreamer 先从真实数据中学出世界模型（编码器 + 动态模型 + 奖励模型），然后让智能体**完全在这个学到的"梦境"里做梦试错**，只在梦境里调整决策网络；策略提升后再回现实采样新数据，继续完善世界模型。这极大减少了现实交互次数——毕竟在现实里撞坏一辆车，和在梦里撞坏一辆车，成本天差地别。

### 3.4 那么，Sora 算"世界模型"吗？

很多人把 Sora 当世界模型，因为它生成的视频有惊人的时空连续性。Sora 确实涌现出了一些**直觉物理**能力——物体遮挡、光影变化。

但从第一性原理看，要严谨地区分：

- Sora 是一个**以视频生成为目标**的扩散/生成模型，根据文本生成未来视频帧，**没有显式的动作输入，也没有奖励输出**。
- 严格意义上用于决策的世界模型，必须能接受**干预**、评估**后果**。

所以更准确的说法是：**Sora 这类视频生成器是一种"无需动作的生成式世界模型雏形"**——它展现了"直觉物理"的潜力，但还不是工程师可以直接拿来训练机器人或自动驾驶的决策引擎。Genie 2 比 Sora 更接近世界模型，因为它生成的世界是 action-controllable（可由动作控制）的。

未来真正值得期待的，是**把视频生成模型、LLM 的语义推理、和显式的动作规划结合起来**，造出通用的"想象引擎"。

## 四、全貌对比：从语言到行动的认知金字塔

三块拼图凑齐了，放一起看：

| 概念 | 第一性原理 | 序列里装什么 | 能干预环境吗？ |
|------|-----------|-------------|---------------|
| **LLM** | 据上下文预测下一个词 | 文本 token | 否，被动生成 |
| **VLA** | 视觉/语言/动作统一为序列，预测动作 | 图像 + 文本 + 动作 token（或连续动作） | 是，动作即干预 |
| **世界模型** | 据潜状态和动作预测下一状态与奖励 | 抽象潜状态 + 动作 | 是，内部动作干预 |

它们并非孤立发展，而是相互增强：

- **LLM 给 VLA 当常识大脑**：VLA 通常以 LLM 为骨干，继承语义、社会常识、甚至简单的物理直觉，让它听得懂"把易碎品轻拿轻放"。
- **世界模型给 VLA 当"心理演练场"**：VLA 执行前，可以先用世界模型在脑内推演动作后果——机器人可以在脑里模拟推箱子、看会不会倒，再实际下手，避免危险试错。
- **LLM 给世界模型当"战略参谋"**：LLM 可以先把复杂任务（"整理房间"）拆成子任务序列，再由世界模型和 VLA 协同执行。

于是形成了一个完整的认知架构：**顶层有 LLM 做规划，中层有世界模型做仿真，底层有 VLA 做执行**。这正是当下业界通往通用智能体（AGI）的主流路线图。

## 五、用费曼的方式讲给奶奶听

为了确保真正消化，用最通俗的类比再复述一遍：

- **大语言模型**像一个读过全世界书的人。你给他起个头，他就顺着往下编，编得有理有据。但他脑袋里没有真实世界，只有文字的逻辑。
- **VLA 模型**是给这位读书人装上眼睛和手。他能看到桌上的东西，你说"把蓝色杯子拿过来"，他就能听懂话、认出蓝杯子、控制手去拿。他的知识不再只停留在嘴上，变成了行动。
- **世界模型**是给这个有手有眼的人一项"白日梦"技能。他做事之前，可以先在脑子里放一遍动画——杯子会不会掉、会不会撞到——挑最安全省力的方式再动手。这样不用每次摔了才知道疼。

这三个方向正在融合。终极目标，是造出能在真实世界里像人一样**学习、想象、行动**的智能体。而从第一性原理看，它们的底层逻辑惊人地统一：

> **把信息序列化，预测下一个元素，并在其中嵌入对世界结构的隐式学习。**

区别只在于：这串序列里承载的是文字、视觉、动作，还是抽象的状态。从第一性原理出发，任何复杂系统都会变得清晰——希望这份讲解能帮你彻底拿下这三个核心概念。
